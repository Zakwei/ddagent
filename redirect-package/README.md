## Install

See the [GitHub repository](https://github.com/Zakwei/ddagent#install) — the `install.sh` one-liner, prebuilt server tarballs, and the Flutter client for web, desktop and Android.

The server listens on **http://localhost:3001** by default and serves the REST/WebSocket API; point the Flutter client at that address. Existing agent sessions are discovered automatically.
