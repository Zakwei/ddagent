## [0.6.0] - 2026-09-26

### 새로운 기능

- **Auto 오케스트레이션 프로바이더** — 모델 라우팅, 플래너 DAG 및 위임. 채팅에 라우팅/플랜/위임/요약 카드와 설정의 오케스트레이션 탭 추가
- **모바일: 완전한 네이티브 전환** — 모든 화면이 이제 네이티브입니다: Files(CRUD, 검색, 라이트박스), Source Control(헝크 스테이징, 분할 diff, 커밋 그래프, 워크트리), Tasks(PRD 편집기, 세부 편집), Agent Board, Quota & Usage, 터미널, 편집기 및 모든 설정 탭
- **모바일:** 온보딩 마법사, 프로젝트 생성 마법사(폴더 브라우저, GitHub 클론, 검토), 전역 검색이 있는 명령 팔레트, 분할 작업 공간 그리드, 빠른 설정 패널, browser-use 라이브 패널
- **모바일:** 오프라인 메시지 큐, 채팅 내보내기(PDF/md/html/text), 대화록 검색, 세션 비교

### 버그 수정

- OpenCode: 스트리밍된 텍스트 스냅샷으로 인한 세션 행 중복, question 도구 프롬프트가 표시되지 않는 문제
- 고정된 Review/Search 바가 첫 번째 메시지를 가리던 문제

## [0.5.9] - 2026-09-25

첫 공개 오픈소스 릴리스 — **AGPL-3.0-only**.

### 새로운 기능

- **팀 협업** — 공유 세션, 브로드캐스트 메시지, 에이전트 받은 편지함, 프로젝트별 공유 메모리
- **MCP 서버** — 외부 MCP 클라이언트(Claude Desktop, OpenClaw)가 `POST /mcp`로 태스크 생성 및 세션 메시지 전송 가능([문서](https://github.com/Zakwei/ddagent/blob/main/docs/mcp-server.md))
- **원격 승인** — Telegram 또는 Discord에서 에이전트 작업 승인([문서](https://github.com/Zakwei/ddagent/blob/main/docs/remote-approvals.md))
- **스케줄러** — 절전 방지 기능이 있는 에이전트 실행용 cron 스케줄
- **이름 있는 프로바이더 계정** — 세션별 환경 변수/자격 증명 재정의
- **음성 입력(STT)** — 컴포저의 Whisper 호환 엔드포인트
- **워크트리** — dev-server 러너가 포함된 리포지토리별 설정/실행 스크립트
- **미리보기** — WS 터널이 있는 인증된 dev-server 미리보기 프록시
- **모바일** — 세션 검색, 실행 가능한 승인 푸시 알림(FCM)
- `SECURITY.md` — 비공개 취약점 보고 정책

### 버그 수정

- 쿼터 탭 데이터 및 표시 버그
- 채팅: 오프라인 큐와 임시 저장이 새로고침 후에도 유지. 다시 가져올 때 스크롤 위치 안정
- 세션: 삭제된 세션이 다른 클라이언트에 유령으로 남지 않음
- 칸반: 에이전트 보드의 디스패치 경합 및 누수
- 모바일: 키보드 높이 패딩, 오버플로 알림을 ActionSheet로 대체

## [0.5.0] - 2026-09-21

**ddagent**의 첫 독립형 릴리스 — AI 코딩 에이전트를 위한 셀프 호스팅 웹 & 모바일 UI.

### 주요 기능

- **멀티 에이전트 세션** — Claude Code, Codex, Cursor CLI, OpenCode, Devin을 나란히 사용. 라이브 스트리밍 및 재개 지원
- **워크스페이스 레이아웃** — 채팅, 터미널, 브라우저, 파일용 분할 창
- **파일 탐색기 및 편집기** — UI에서 워크스페이스 탐색 및 편집
- **Git 패널** — 스테이지, 커밋, diff, 브랜치 전환, 워크트리 관리
- **태스크 보드** — TaskMaster 기반 칸반. PRD에서 실행 가능한 태스크 생성
- **MCP 관리** — 에이전트 간 MCP 서버 추가 및 동기화
- **스킬 브라우저** — 에이전트 스킬 검색 및 관리
- **쿼터 및 사용량** — 에이전트별 토큰 사용량 및 구독 한도
- **Browser-use** — 조사 및 테스트용 에이전트 구동 브라우저 세션
- **알림 및 TTS** — 알림 및 읽어주기 답변
- **Docker 샌드박스** — 실험적 하이퍼바이저 격리 에이전트 실행
- **데스크톱 컴패니언** — macOS/Windows용 선택적 Electron 앱
- **i18n** — 11개 UI 언어, 다크/라이트 테마

### CLI

- `ddagent` / `ddagent start` — 서버 시작
- `ddagent status` — 구성 및 데이터 위치 표시
- `ddagent version` / `ddagent help`
