## [0.6.0] - 2026-09-26

### 新機能

- **Auto オーケストレーションプロバイダー** — モデルルーティング、プランナー DAG、デリゲーション。チャット内にルーティング/プラン/デリゲーション/サマリーカードを表示し、設定にオーケストレーションタブを追加
- **モバイル: 完全なネイティブ対応** — すべての画面がネイティブになりました: Files（CRUD、検索、ライトボックス）、Source Control（ハンクステージング、分割 diff、コミットグラフ、ワークツリー）、Tasks（PRD エディター、詳細編集）、Agent Board、Quota & Usage、ターミナル、エディター、すべての設定タブ
- **モバイル:** オンボーディングウィザード、プロジェクト作成ウィザード（フォルダーブラウザー、GitHub クローン、レビュー）、グローバル検索付きコマンドパレット、分割ワークスペースグリッド、クイック設定パネル、browser-use ライブパネル
- **モバイル:** オフラインメッセージキュー、チャットエクスポート（PDF/md/html/text）、トランスクリプト検索、セッション比較

### バグ修正

- OpenCode: ストリーミングされたテキストスナップショットによるセッション行の重複、question ツールのプロンプトが表示されない問題
- 固定の Review/Search バーが最初のメッセージを隠していた問題

## [0.5.9] - 2026-09-25

初の公開オープンソースリリース — **AGPL-3.0-only**。

### 新機能

- **チームコラボレーション** — 共有セッション、ブロードキャストメッセージ、エージェント受信ボックス、プロジェクトごとの共有メモリ
- **MCP サーバー** — 外部 MCP クライアント（Claude Desktop、OpenClaw）が `POST /mcp` でタスクの作成やセッションへのメッセージ送信が可能（[ドキュメント](https://github.com/Zakwei/ddagent/blob/main/docs/mcp-server.md)）
- **リモート承認** — Telegram や Discord からエージェントの操作を承認（[ドキュメント](https://github.com/Zakwei/ddagent/blob/main/docs/remote-approvals.md)）
- **スケジューラー** — スリープ防止付きのエージェント実行用 cron スケジュール
- **名前付きプロバイダーアカウント** — セッションごとの環境変数・認証情報の上書き
- **音声入力（STT）** — コンポーザー内の Whisper 互換エンドポイント
- **ワークツリー** — dev-server ランナー付きのリポジトリごとのセットアップ/実行スクリプト
- **プレビュー** — WS トンネル付きの認証済み dev-server プレビュープロキシ
- **モバイル** — セッション検索、アクション可能な承認プッシュ通知（FCM）
- `SECURITY.md` — 非公開の脆弱性報告ポリシー

### バグ修正

- クォータタブのデータと表示の不具合
- チャット: オフラインキューと下書きがリロード後も保持。再取得時もスクロール位置が安定
- セッション: 削除されたセッションが他のクライアントにゴーストとして残らなくなりました
- カンバン: エージェントボードでのディスパッチ競合とリーク
- モバイル: キーボード高さのパディング、オーバーフローアラートを ActionSheet に置き換え

## [0.5.0] - 2026-09-21

**ddagent** の初のスタンドアロンリリース — AI コーディングエージェント向けセルフホスト型 Web＆モバイル UI。

### ハイライト

- **マルチエージェントセッション** — Claude Code、Codex、Cursor CLI、OpenCode、Devin を並べて利用。ライブストリーミングと再開に対応
- **ワークスペースレイアウト** — チャット、ターミナル、ブラウザ、ファイルの分割ペイン
- **ファイルエクスプローラー＆エディター** — UI 内でワークスペースを参照・編集
- **Git パネル** — ステージ、コミット、差分、ブランチ切替、ワークツリー管理
- **タスクボード** — TaskMaster によるカンバン。PRD から実行可能なタスクを生成
- **MCP 管理** — エージェント間で MCP サーバーを追加・同期
- **スキルブラウザー** — エージェントスキルの発見と管理
- **クォータ＆使用状況** — エージェントごとのトークン使用量とサブスクリプション上限
- **Browser-use** — 調査とテストのためのエージェント駆動ブラウザセッション
- **通知＆TTS** — アラートと読み上げ返信
- **Docker サンドボックス** — 実験的なハイパーバイザー分離エージェント実行
- **デスクトップコンパニオン** — macOS/Windows 向けオプションの Electron アプリ
- **i18n** — 11 の UI 言語、ダーク/ライトテーマ

### CLI

- `ddagent` / `ddagent start` — サーバーを起動
- `ddagent status` — 設定とデータの場所を表示
- `ddagent version` / `ddagent help`
