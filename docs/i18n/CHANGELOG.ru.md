## [0.6.0] - 2026-09-26

### Что нового

- **Оркеструемый провайдер Auto** — маршрутизация моделей, планировщик DAG и делегирование с карточками маршрутизации/плана/делегирования/итогов в чате, а также вкладка оркестровки в настройках
- **Мобильное приложение: полный нативный паритет** — все экраны теперь нативные: Files (CRUD, поиск, лайтбокс), Source Control (стейджинг ханков, разделённый diff, граф коммитов, worktree), Tasks (редактор PRD, редактирование деталей), Agent Board, Quota & Usage, терминал, редактор и все вкладки настроек
- **Мобильное приложение:** мастер онбординга, мастер создания проекта (обзор папок, клонирование с GitHub, проверка), палитра команд с глобальным поиском, разделённая сетка рабочей области, панель быстрых настроек, live-панель browser-use
- **Мобильное приложение:** офлайн-очередь сообщений, экспорт чата (PDF/md/html/text), поиск по транскрипту, сравнение сессий

### Исправления

- OpenCode: дублирование строк сессий из стриминговых снимков текста, промпты инструмента question не отображались
- Закреплённая панель Review/Search обрезала первое сообщение

## [0.5.9] - 2026-09-25

Первый публичный релиз с открытым исходным кодом — **AGPL-3.0-only**.

### Что нового

- **Командная работа** — общие сессии, широковещательные сообщения, входящие агента, общая память по проектам
- **MCP-сервер** — внешние MCP-клиенты (Claude Desktop, OpenClaw) могут создавать задачи и отправлять сообщения в сессии через `POST /mcp` ([документы](https://github.com/Zakwei/ddagent/blob/main/docs/mcp-server.md))
- **Удалённые подтверждения** — подтверждение действий агента из Telegram или Discord ([документы](https://github.com/Zakwei/ddagent/blob/main/docs/remote-approvals.md))
- **Планировщик** — cron-расписания для запусков агента с предотвращением сна
- **Именованные аккаунты провайдеров** — переопределение env/учётных данных для каждой сессии
- **Голосовой ввод (STT)** — Whisper-совместимый эндпоинт в поле ввода
- **Worktree** — скрипты настройки/запуска для каждого репозитория с запуском dev-сервера
- **Предпросмотр** — аутентифицированный прокси предпросмотра dev-сервера с WS-туннелем
- **Мобильное приложение** — поиск по сессиям, push-уведомления о подтверждениях с действиями (FCM)
- `SECURITY.md` — политика конфиденциального сообщения об уязвимостях

### Исправления

- Ошибки данных и отображения на вкладке квот
- Чат: офлайн-очередь и черновики сохраняются после перезагрузки; стабильная позиция прокрутки при повторной загрузке
- Сессии: удалённые сессии больше не оставляют «призраков» на других клиентах
- Канбан: гонки при отправке и утечки на доске агентов
- Мобильное приложение: отступ по высоте клавиатуры, ActionSheet вместо переполненных алертов

## [0.5.0] - 2026-09-21

Первый автономный релиз **ddagent** — self-hosted веб- и мобильный UI для AI-агентов кодирования.

### Основное

- **Мультиагентные сессии** — Claude Code, Codex, Cursor CLI, OpenCode и Devin рядом, с живым стримингом и возобновлением
- **Раскладка рабочего пространства** — разделённые панели для чата, терминала, браузера и файлов
- **Файловый менеджер и редактор** — просмотр и редактирование рабочего пространства в UI
- **Панель Git** — стейджинг, коммиты, diff, переключение веток, управление worktree
- **Доска задач** — канбан на TaskMaster; генерация исполняемых задач из PRD
- **Управление MCP** — добавление и синхронизация MCP-серверов между агентами
- **Браузер скиллов** — поиск и управление скиллами агентов
- **Квоты и использование** — расход токенов по агентам и лимиты подписки
- **Browser-use** — управляемые агентом браузерные сессии для исследований и тестирования
- **Уведомления и TTS** — оповещения и озвучивание ответов
- **Docker-песочницы** — экспериментальные запуски агентов с изоляцией гипервизором
- **Десктопный компаньон** — опциональное Electron-приложение для macOS/Windows
- **i18n** — 11 языков интерфейса, тёмная и светлая темы

### CLI

- `ddagent` / `ddagent start` — запустить сервер
- `ddagent status` — показать конфигурацию и расположение данных
- `ddagent version` / `ddagent help`
